# Zeny-Pay organization profile

`profile/README.md` is the public homepage of the [Zeny-Pay](https://github.com/Zeny-Pay) organization on GitHub.
GitHub only renders it from a public repository named `.github`.

- `profile/README.md`: the page
- `profile/assets/banner.svg`: hero banner (Volt palette, fixed dark background so it reads on both GitHub themes)
- `profile/assets/zeny-logo.svg`, `zeny-mark.svg`: brand assets, copied from the main repo's `docs/assets/`

Copy is taken from usezeny.com. Change both when product facts change.
